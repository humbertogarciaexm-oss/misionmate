# Misión Mate

Práctica de Matemática de 1° básico a 4° medio, pensada para estudiantes con TDAH: mini lecciones con ejemplos narrados paso a paso, misiones cortas de 5 preguntas, pistas, pausas activas y panel de control para el adulto a cargo.

**Abrir la app:** https://humbertogarciaexm-oss.github.io/misionmate/

**Cuenta genérica:** usuario `estudiante`, clave `mate2026`.

Las cuentas y el progreso se guardan en el navegador de cada dispositivo. Para actualizar la app, reemplaza `index.html`.
